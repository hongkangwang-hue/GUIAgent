# 服务器端依赖（无头 Linux + GPU）。
#
# ## 为什么单独一份，而不是直接用 requirements.txt
#
# 本项目的感知与控制层是 **Windows + 真实桌面** 专有的，在无头 Linux 上
# 装不上、也跑不了：
#
#   dxcam / uiautomation  已有 sys_platform == "win32" 标记，会自动跳过
#   pyautogui / pynput    **没有标记**，Linux 上会去装 Xlib，
#                         无头环境下 import 就抛 DISPLAY 错误
#   paddleocr / easyocr   感知侧才用，几百 MB，服务器上纯浪费
#   opencv-python         会拉一堆 GUI 库依赖，服务器要用 headless 版
#
# 服务器只负责三件**没有桌面依赖**的事：
#   1. LoRA 训练（M3 P0）
#   2. ScreenSpot 批量评测（M3 挂机线）
#   3. 微调模型的推理服务（开发调试期用，见下方说明）
#
# GUI Agent 的执行端永远在本地 Windows。服务器不是"换个地方跑同一套
# 东西"，是接管 GPU 那部分。

# --- 深度学习基础 ---
# ⚠ torch 的 cu 版本按服务器显卡算力选，本文件**不能钉死**。
# 先查算力：nvidia-smi --query-gpu=name,compute_cap --format=csv
#   sm_75  (T4 / Turing)          → cu121
#   sm_80  (A100 / Ampere)        → cu121
#   sm_86  (RTX 30xx / A10)       → cu121
#   sm_89  (RTX 40xx / L4 / L40S) → cu121 或 cu124
#   sm_90  (H100 / Hopper)        → cu124+
#   sm_120 (RTX 50xx / Blackwell) → cu128+，需 torch 2.7+
# 装错不会报错，而是"能导入、一运算就崩"——本项目在开发机上已经踩过
# 一次，详见 docs/开发环境配置文档.md 第 3 节。
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
torch>=2.5.0
